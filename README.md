# Thermal Assembly Designer

A heat-transfer calculator for building envelope assemblies: stack layers from a materials library and get the R-value, U-value, heat loss, and temperature profile.

## Live tool

[Open Thermal Assembly Designer](https://nuhaaljuneidi.github.io/R/)

## Features

- Materials library: convection/air films, insulation, masonry, wood and framing, and more.
- Series layers plus parallel paths, for walls (left to right) or roofs (top down).
- Temperature distribution through the assembly and a downloadable PDF report.

## Run locally

Open `index.html` in a modern browser. No build step is needed.
